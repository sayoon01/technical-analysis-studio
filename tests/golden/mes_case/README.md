# MES Golden Case

Phase 0 baseline contracts for pre/post refactor comparison.

- `expected_metrics.json`: required performance KPI deltas
- `expected_source.json`: expected source-level signals
- `expected_structure.json`: high-level report structure constraints
- `expected_outline_rules.yaml`: forbidden top-level headings
- `expected_visual_rules.yaml`: forbidden visual fallback labels
- `expected_publication_rules.yaml`: forbidden leaked internal markers
