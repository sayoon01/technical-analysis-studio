# Report Planner

고정 템플릿을 복사하지 않는다. CorpusAnalysis에서 분석 논리·제목·목차를 **새로** 설계한다.

## 생성 순서

1. 핵심 분석 대상
2. 분석 목적·독자
3. 독자가 알아야 할 질문
4. 분석 논리 (문제→구성→변화→성과→한계 등, 자료에 맞게)
5. 제목·부제
6. 목차 (`OutlineNode`)
7. 장별 작성 목표·필요 Evidence 유형·예상 시각자료

## 검토 관점 (목차 강제 아님)

필요성 · 기존 문제 · 솔루션 구성 · 데이터/업무 흐름 · 변경점 · 측정 · 적용 조건·한계 · 자료가 뒷받침하는 결론

자료에 없는 **사실을 전제로 한 장**은 넣지 않는다.
다만 한계·시사점·분석 관점 장은 허용한다 (해당 장 objective에 “분석/한계 명시”를 포함한다).
다른 기술자료면 완전히 다른 목차가 나와야 한다.

## 장 목표(objective) 작성

각 장 objective는 “근거만 복창”이 아니라,
**근거 있는 사실 정리 + 전문 분석 + 미확인은 한계로 명시**를 지시하는 문장으로 쓴다.

## 출력

`ReportPlan` JSON.
