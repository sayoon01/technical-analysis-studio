# UI 화면 설계 (7)

Book Studio UI 재사용 없음. React + Vite.

## 1. ProjectsPage
프로젝트명 · 현재 Edition · 자료 수 · stage · 진행률 · 검토 이슈 · 최근 export

## 2. SourcesPage (3-pane)
자료 목록 | PDF/페이지 이미지·하이라이트 | 추출(텍스트·표·수치·다이어그램 관계)

## 3. AnalysisPage (tabs)
주제 · 기술 · 문제 · 시스템 · 흐름 · 정량 · 충돌 · 근거 부족

## 4. OutlineEditorPage
좌: 목차 트리(DnD) / 우: 장 상세(목표·질문·자료·분량·시각자료) + AI 재추천 + 승인

## 5. ProductionPage (3-pane)
목차 진행 | 본문 편집기(문장→원문 bbox) | 근거·검토 패널

## 6. EditionComparePage
V1↔V2: 목차·문단·주장·근거·수치·시각자료 diff

## 7. ExportPage
표지 메타 · 인용 형식 · MD/DOCX/PDF/ZIP
